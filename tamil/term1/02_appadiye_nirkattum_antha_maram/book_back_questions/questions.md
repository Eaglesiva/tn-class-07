### மதிப்பீடு

ரியான விடையைத் தேர்ந்தெடுத்து எழுதுக.

1. நாவறப்பழத்திற்கு உவமையாக் கூறப்படுவது _____.
   (அ) பச்சை இலை
   (ஆ) கோலிக்குண்டு
   (இ) பச்சைக்காய்
   (ஈ) செங்காய்

2. ‘சுட்ட பழங்கள்’ என்று குறிப்பிடப்படுபவை _____.
   (அ) மண் ஒட்டிய பழங்கள்
   (ஆ) டான பழங்கள்
   (இ) வேகவைத்த பழங்கள்
   (ஈ) சுடப்பட்ட பழங்கள்

3. ‘பெயரறியா’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது _____.
   (அ) பெயர +றியா
   (ஆ) பெயர் +ரறியா
   (இ) பெயர் + அறியா
   (ஈ) பெயர + அறியா

4. ‘மனமில்லை’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது _____.
   (அ) மன + மில்லை
   (ஆ) மனமி + இல்லை
   (இ) மனம் + மில்லை
   (ஈ) மனம் + இல்லை

5. நேற்று + இவைு என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் _____.
   (அ) நேற்றுஇவைு
   (ஆ) நேற்றிவைு
   (இ) நேற்றுவைு
   (ஈ) நேற்இவைு

2. சிறுவர்களுக்கு நாவறப்பழம் கிடைக்க உதவியோர் யாவர்?
